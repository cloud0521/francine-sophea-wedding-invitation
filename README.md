# Sophea and Francine Dale Wedding Invitation

Standalone React and Vite wedding invitation for the `FRANCINEDALEandSOPHEA` path on dreamzinvites.asia.

## Run locally

1. Install dependencies with `npm install`.
2. Start the preview with `npm run dev`.

The Vite base path is set to `/FRANCINEDALEandSOPHEA/` to match the requested URL.

## Content status

The first site draft uses the supplied names, date, ceremony and reception information, attire palette, guest rules, gift note, entourage list, and ten supplied couple photos. The love story paragraph is drafted from the short client wording.

Before launch, confirm the RSVP deadline, reserved seat count, response destination, map pins, the names and pairings in the principal sponsor list, and the exact reception venue name. The client intake says messages are disabled; the current RSVP form is a visual interaction only and does not send or store responses. No background music is included because no audio file was supplied.
